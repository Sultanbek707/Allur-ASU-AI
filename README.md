# Цифровой двойник автомобильного завода

Прототип для кейса 2 «Цифровой двойник автомобильного завода» (АО «Группа компаний АЛЛЮР»), Qostanai AI Industry Hackathon 2026.

**Демо:** https://ВАШ-ЛОГИН.github.io/НАЗВАНИЕ-РЕПОЗИТОРИЯ/  
**Версия на казахском:** https://ВАШ-ЛОГИН.github.io/НАЗВАНИЕ-РЕПОЗИТОРИЯ/kk.html

## Что делает прототип
- Схема из 10 участков завода: кузова движутся по конвейеру, за остановившимся участком растёт очередь.
- KPI смены: выпуск против плана, прогноз смены, OEE, качество с первого раза, простой линии.
- Лента событий и отклонений, запас комплектующих в часах работы.
- Прогноз остановки оборудования по тренду вибрации и температуры, поиск узкого места.
- ИИ-диспетчер: конкретное действие, выигрыш в минутах и тенге.
- Расчёт бизнес-эффекта с ползунками.

Три сценария для демо: сбой сварочного робота, задержка поставки дверей, брак покраски.

## Как запустить
Откройте `index.html` в любом браузере. Установка и интернет не нужны.

## Архитектура
Источники данных (MES, SCADA, планы, склад, контроль качества) → слой данных → аналитика и ИИ → веб-панель. В прототипе все блоки работают в одном браузере, данные синтетические.

## Технологии и внешние компоненты
HTML, CSS, JavaScript, SVG. Внешних библиотек и сервисов нет.

## Данные
Синтетические, генерируются в браузере. Данные АЛЛЮР в репозиторий не загружались.

## Использование ИИ при разработке (п. 6.4 Положения)
Инструмент: Claude (Anthropic).

## Ограничения
- Прогноз простоев основан на тренде вибрации и температуры, а не на обученной ML-модели.
- Расчёт эффекта (~180 млн ₸ в год) условный и требует уточнения по журналу простоев АЛЛЮР.
